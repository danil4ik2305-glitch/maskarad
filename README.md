# Маскарад — веб-приложение для проката костюмов

Учебная практика УП.09.01. Студент: Сулайманов Даниил Романович, группа ВД-5-23.

Веб-приложение позволяет просматривать каталог костюмов, бронировать костюмы на выбранные даты,
вести личный кабинет, оставлять отзывы. Администратор управляет всеми таблицами базы данных через админ-панель.

## Технологии
HTML5, CSS3, JavaScript, PHP 8, MySQL (MariaDB), API [Nager.Date](https://date.nager.at) — календарь праздников.

## Запуск проекта
1. Установите [XAMPP](https://www.apachefriends.org/) (Apache + PHP 8 + MySQL).
2. Скопируйте папку проекта `maskarad` в каталог `xampp/htdocs`.
3. Запустите модули **Apache** и **MySQL** в панели управления XAMPP.
4. Откройте http://localhost/phpmyadmin, перейдите на вкладку «Импорт» и импортируйте файл
   `database/costume_rental.sql` (будет создана база данных `costume_rental` с таблицами, представлениями и тестовыми данными).
5. При необходимости измените параметры подключения к БД в файле `includes/db.php`.
6. Откройте сайт: http://localhost/maskarad/

## Структура
- `index.php`, `catalog.php`, `costume.php`, `booking.php`, `about.php`, `rules.php`, `reviews.php`, `contacts.php` — страницы сайта
- `login.php`, `register.php`, `logout.php`, `account.php` — авторизация, регистрация, личный кабинет
- `admin/index.php` — административная панель
- `includes/` — подключение к БД, шапка и подвал
- `css/`, `js/`, `img/` — стили, скрипты, изображения
- `database/costume_rental.sql` — дамп базы данных
